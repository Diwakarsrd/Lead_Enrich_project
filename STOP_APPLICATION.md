# How to Stop the Application

The Streamlit application is currently running in the background. To stop it:

1. Go to the terminal where you ran `streamlit run app.py`
2. Press `Ctrl+C` to stop the server

Alternatively, you can:
1. Close the terminal window
2. Or find the process in Task Manager and end it

The application will be accessible at:
- Local URL: http://localhost:8501
- Network URL: http://192.168.0.114:8501 (if accessible on your network)
